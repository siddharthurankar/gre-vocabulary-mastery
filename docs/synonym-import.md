# Instructor synonym library

Source: Synonym_Groups.pdf, 99 pages. Imported on October 23, 2026.

685 blue meaning headings, 2,052 entries, 137 groups of five consecutive headings. Original sequence, definitions, combined word-form labels, repeated placements and usage notes are retained. The wrapped heading on page 92 is a single heading. The inline compendium entry under Concise Style is retained. Headings that only refer to another family remain in sequence with their reference text; they are not assigned invented word lists.

Existing data.json and its 39 groups are unchanged. Synonym placement IDs and sense-specific progress keys are separate; existing scores and saved sessions are preserved. Original quizzes continue drawing distractors from the original library. New quizzes draw from the synonym library, excluding overlapping meaning families and duplicate answer spellings.

Learning cards use the source definition as the intended sense. They show the instructor’s usage distinctions, related words, a meaning association, speech controls, and source page. Practice blanks the target word from a source usage sentence when possible. Exact definition matches may reuse existing authored contexts. Otherwise, explicit meaning-in-use word-choice situations provide practice; these are labelled, not represented as realistic GRE Text Completion. Some words have one suitable source usage context. This is not a claim of full editorial review of all generated distractor combinations.

Regression checks cover every imported entry in both quiz stages, source order, five-family grouping, unique placements, backup compatibility, and preservation of the original dataset.
